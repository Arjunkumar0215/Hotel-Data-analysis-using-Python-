# Hotel-Data-analysis-using-Python-
#  Blue Star Hotels Data Analysis Project

##  Project Overview

This project focuses on analyzing hotel booking data to uncover meaningful business insights related to **bookings, occupancy, revenue, room categories, hotel performance, and booking platforms**.

The analysis was performed using Python and Pandas, covering the complete data analysis workflow from **data exploration and cleaning to transformation and insight generation**.

This project is a **good addition to your Data Analyst fresher portfolio** because it demonstrates actual data cleaning, transformation, EDA, and business insight generation rather than just machine-learning models.

##  Objectives

- Analyze hotel booking patterns
- Calculate occupancy rates
- Identify hotel and city-wise performance
- Analyze revenue generated by different cities and hotel types
- Compare weekday and weekend occupancy
- Analyze booking platforms
- Identify data quality issues and clean the dataset
- Generate business insights from the available data

## 📂 Datasets

The project uses 5 CSV datasets:

- `dim_date.csv`
- `dim_hotels.csv`
- `dim_rooms.csv`
- `fact_aggregated_bookings.csv`
- `fact_bookings.csv`

##  Analysis Performed

### 1. Data Exploration
- Loaded and explored multiple CSV datasets
- Checked dataset shape and structure
- Analyzed unique room categories
- Analyzed booking platforms
- Examined descriptive statistics

### 2. Data Cleaning
- Identified invalid guest records
- Handled data quality issues
- Analyzed revenue outliers
- Examined missing values
- Filtered records where successful bookings exceeded capacity

### 3. Data Transformation
- Created occupancy percentage
- Merged and aggregated datasets
- Created new analytical columns
- Converted values into appropriate formats

### 4. Insights Generation
The project analyzes:

- Average occupancy by room category
- Average occupancy by city
- Weekday vs weekend occupancy
- June occupancy by city
- Monthly revenue
- Revenue by city
- Revenue by hotel type
- Average hotel rating by city
- Revenue by booking platform
